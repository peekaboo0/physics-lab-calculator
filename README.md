# Physics Lab Calculator

A VB.NET Windows Forms application designed to assist with common introductory physics laboratory calculations.

## Features

- Ohm's Law calculator
- Simple Harmonic Motion calculator
- Standing Wave calculator
- Percentage Error calculator
- Input validation
- Multi-form navigation

## Technologies

- Visual Basic .NET
- Windows Forms
- Visual Studio

## Physics Calculations

### Ohm's Law

R = V / I

### Simple Harmonic Motion

f = 1 / T

ω = 2πf

### Standing Waves

λ = 2L / n

v = fλ

### Percentage Error

Percentage Error = |Experimental - Theoretical| / |Theoretical| × 100
